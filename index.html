Three projects, one path through a support desk

A customer message arrives from any channel. An agent reads it, decides what kind of problem it is and how urgent, then routes it — to a person, or to a system that handles that domain. Each project stands alone. Together they trace one request end to end.

Solid lines are wired. Dashed lines are the hand-off interface — defined, routed and tested, with the connection to each system still to build.

Customer support ticket triage agent

the front door

Messages arrive from social platforms and from a tablet at the counter. A pydantic-ai agent reads each one and returns structured output — issue type, urgency, a confidence score — which drives where the ticket goes next. Low confidence goes to a human rather than being trusted.

0tests passing, no network calls
0concurrent threads, ticket numbering tested
0channels behind one interface

Ticket numbers come from an atomic upsert on a daily counter, so two requests can never take the same number. Customer text is treated as untrusted in four layers, ending with a typed schema the model can only fill — there is no free-text channel for an injected instruction to land in.

RAG-based WISP monitoring assistant

the network specialist

Ask what happened on a given night and get an answer drawn from router logs, incident notes and playbooks. It runs entirely on a local model with no API key, because network logs expose topology, customers and weak points — exactly what cannot be pasted into a hosted service.

0/21evaluation questions passing
0indexed chunks across logs, notes, playbooks
0API keys required

Every citation is checked against the evidence actually retrieved, so the model cannot invent a source. Dates, towers and time windows are extracted by rule rather than by embedding — two near-identical log days look the same in vector space, and only a filter can tell them apart.

Burmese PC troubleshooting chatbot

the hardware specialist

A bilingual assistant for the questions a repair counter answers every day — a PC that will not start, a driver that will not install, Wi-Fi that drops. Burmese or English, one toggle apart, with matching on character n-grams because written Burmese has no spaces between words.

0tests
0%backend coverage
0curated troubleshooting entries

Two storage layers, deliberately separate. Curated answers never change; a second cache fills up with answers the model has already given, so repeated questions stop costing anything. The system gets cheaper the longer it runs, and generated text can never quietly overwrite what was checked by hand.
